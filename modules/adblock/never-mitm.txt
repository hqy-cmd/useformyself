# Hosts the generated AdBlock modules must never decrypt (MITM). Any upstream module entry that
# needs one of these hosts is dropped, and the run fails if a generated module would still list
# one. Hosts from rules/AI_Domain.list are added automatically.
#
# Syntax: one host glob per line (`*` and `?` as in Surge's hostname list);
# `.example.com` = example.com and *.example.com. `#` starts a comment.
#
# [guard]         also exported to both AdBlock modules (and the deprecated MITM-Guard.sgmodule) as
#                 `-host` exclusions placed FIRST with %INSERT%, so no other module can decrypt them either
# [adblock-only]  only keeps the generated AdBlock modules away from these hosts; other modules
#                 you install on purpose (WLoc on gs-loc.apple.com, YouTube, Apple weather ...)
#                 keep working
