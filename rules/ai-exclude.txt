# Exclusions applied to the merged upstream AI rules.
#
# Syntax (one per line, `#` starts a comment, `[name]` starts a report category):
#   DOMAIN,example.com           exact name: drops `example.com` whether upstream has it as
#                                DOMAIN or DOMAIN-SUFFIX; subdomains listed separately are kept
#   DOMAIN-SUFFIX,example.com    drops example.com and every entry under it
#   DOMAIN-WILDCARD,cici*.com    shell-style pattern matched against the name and each parent
#                                (so `cici*.com` also drops www.ciciai.com)
#   DOMAIN-KEYWORD,sentry        drops that DOMAIN-KEYWORD rule
#   IP-CIDR,1.2.3.0/24           drops CIDRs equal to or inside this range (IP-CIDR6 for IPv6)
#   IP-ASN,14061                 drops that IP-ASN rule
#   .example.com / example.com   shorthand for DOMAIN-SUFFIX / DOMAIN
#
# Excludes run before ai-include.txt, so an include always wins.
