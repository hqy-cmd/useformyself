# Must-not-block guard for the generated ad-block rules.
#
# Every entry here is (1) removed from all upstream input like an exclusion, and (2) checked
# once more against the final outputs (Reject_Domain.list, Reject.list, Reject_Extra_Domain.list,
# including adblock-include.txt). If anything in an output would still match, the run fails and
# nothing is published. Entries of rules/AI_Domain.list are protected the same way automatically.
#
#   DOMAIN,apple.com             this exact host must stay reachable (blocks of .apple.com or
#                                apple.com fail; metrics.apple.com style subdomains may be blocked)
#   DOMAIN-SUFFIX,abchina.com    the whole tree must stay reachable (nothing under it may match)
#   example.com / .example.com   shorthand
#
# Matching follows Surge semantics: a DOMAIN-SET line `.x.com` matches x.com and every
# subdomain; DOMAIN-KEYWORD is a substring test; DOMAIN-WILDCARD `*` crosses dots.
# Apple / Firebase telemetry (metrics.icloud.com, api-adservices.apple.com, iadsdk.apple.com,
# app-measurement.com, firebaselogging-pa.googleapis.com, ...) is intentionally NOT protected.
