# Whitelist for the generated ad-block rules: removed from ALL layers (Reject_Domain.list,
# Reject.list, Reject_Extra_Domain.list).
#
# Syntax (one per line, `#` starts a comment, `[name]` starts a report category):
#   DOMAIN,example.com           example.com itself must not be blocked: drops `example.com`,
#                                `.example.com` and any broader parent suffix; subdomains such as
#                                tracker.example.com stay blocked
#   DOMAIN-SUFFIX,example.com    nothing at or under example.com may be blocked (also drops
#                                parent suffixes, keywords / wildcards / AND rules aimed at it)
#   DOMAIN-WILDCARD,cici*.com    shell-style pattern matched against the name and its parents
#   DOMAIN-KEYWORD,fenxi         drops that DOMAIN-KEYWORD rule
#   URL-REGEX,<regex>            drops that exact URL-REGEX rule
#   AND,((...),(...))            drops that exact logical rule (flags / policy ignored)
#   IP-CIDR,1.2.3.0/24           drops CIDRs equal to, inside or containing this range
#   .example.com / example.com   shorthand for DOMAIN-SUFFIX / DOMAIN
#
# Applied before adblock-include.txt, so an include always wins - except against
# adblock-guard.txt and rules/AI_Domain.list, which are enforced last and fail the run.
